Our Journey gallery
===================
One folder per year: 2022, 2023, 2024, 2025, 2026 ...
The filter shows 2022-2025 always; any other year folder (e.g. 2026) appears in the
filter automatically as soon as it contains at least one photo.
Upload photos (jpg / jpeg / png / webp) into the year folder with cPanel File Manager
or FTP; journey.php reads the folders on every visit and shows a random selection,
so nothing else needs to change. A new year is picked up automatically when its
folder exists (4-digit name).

"undated" holds photos whose year is not yet known; they show only under "All".
Move them into the right year folder when known.
